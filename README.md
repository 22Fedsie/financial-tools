# Financial Tools

Free, practical financial calculators and tools, with a growing library of advanced financial models and Excel-based tools.

The first calculator estimates a monthly mortgage payment using a Canadian semi-annual interest-rate conversion. It is an estimate and excludes property tax, insurance, and other costs.

## Run on your Mac

1. Open Terminal and move into this project folder.
2. Run `python3 -m http.server 8000`.
3. Open <http://localhost:8000> in your browser.
4. Press Control+C in Terminal when you want to stop the local website.

This starter uses plain HTML, CSS, and JavaScript, so it does not need Node.js or extra packages.

## Project files

- `index.html` contains the page content and calculator form.
- `styles.css` controls the layout and appearance.
- `app.js` calculates the estimated payment.

## GitHub

Connect this folder to the `financial-tools` GitHub repository after installing Apple's Command Line Tools, which provide the `git` command-line support on macOS.
