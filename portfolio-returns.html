Which return should I use?

  • HPR summarizes the total gain or loss over one holding period, including cash income.
  • Annualized HPR expresses that result as a compound yearly rate when comparing periods of different lengths.
  • Money-weighted return reflects the timing and size of the investor's actual cash flows.
  • Time-weighted return links subperiod returns to reduce the impact of deposits and withdrawals, which is useful when assessing portfolio management.

These measures can differ without any of them being incorrect. Fees, taxes, inflation, currency changes, and the choice of benchmark also affect how an investor should interpret performance.
